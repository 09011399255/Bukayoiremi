# Bukayo-Iremi Multipurpose Ventures

A modern, high-fidelity website for **Bukayo-Iremi Multipurpose Ventures**, a community savings and short-term credit enterprise based in Ibadan, Oyo State, Nigeria.

## Features

- **Home Page**:
  - Centered Hero with clear value proposition and subtle entrance motion
  - Two-column Savings Visual with live progress animation
  - 4-item Services Strip (30-Day Savings, 12-Month Savings, Short-Term Credit, One-to-One Support)
  - Credibility & Founders section with executive portraits
  - 3-Step "How It Works" with interface overlays
  - Interactive Savings Plans showcase (30-Day & 12-Month cycles, radial gauge, and contribution calendar)
  - Savings Use Cases (Business Restocking, School Fees, Rent & Household Plans, Long-Term Goals)
  - Credit Support section (Request, Review, Agree, Repay)
  - Closing CTA and full-featured Footer
- **About Us Page**:
  - Executive leadership profiles for **Adeyeye Oluwabukola** (Founder & Director) and **Ajayi Kolawole Luke** (Co-founder & Chief Accountant)
  - "Our Story" narrative and operating principles ("What guides us")
  - Direct WhatsApp links for inquiries and credit support
- **Design & Performance**:
  - Built with React, Tailwind CSS, and Lucide React
  - Custom color system: Forest Green (`#073B35`), Green (`#078363`), Pale Mint (`#E5FAF1`), and Bright Lime (`#C9FF55`)
  - Subtle, accessible editorial animations with full `prefers-reduced-motion` compliance
  - High-resolution photography and responsive layouts across desktop, tablet, and mobile

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/09011399255/Bukayoiremi.git

# Navigate into the project folder
cd Bukayoiremi

# Install dependencies
npm install

# Start the local development server
npm run dev
```

### Build for Production
```bash
npm run build
```
